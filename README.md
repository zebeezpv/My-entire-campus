# UCT Student Hub — Phase 2 Static PWA

Upload all files in this folder to the root of your GitHub repository, then deploy the repository to Vercel using the **Other** framework preset. No build command is required.

## Phase 2 features
- Semester calendar with `.ics` export
- Browser deadline notifications
- Pomodoro focus timer that logs completed sessions
- Course notes and useful-link storage
- Analytics for study time, marks, workload and semester progress
- CSV and JSON backup exports
- Existing timetable, assessments, study log, marks and budget features
- Offline PWA support

## Important
Data is stored locally in the browser. Export a JSON backup regularly, especially before clearing browser data or moving to a different phone. Notification behaviour on iPhone may depend on installing the app to the Home Screen and allowing notifications.
